# Двухузловая игрушечная цепочка: когда выход чётен по полю

Система выдуманная: два электрона и три ядра со спином 1/2, осевые тензоры и скорости взяты произвольно.
Пар W_C и W_D, тензоров RadicalPy, геометрии 6PU0 и скоростей Cry4a здесь нет.

Узел «мостик» (*) и конечный узел (CS) имеют разные спиновые гамильтонианы. Пара рождается в мостике в состоянии
P_b, прыгает в CS со скоростью k2 и обратно со скоростью km2, рекомбинирует из мостика через P_CR (kCR) и из CS
через P_CR2 (kCR2), а сигнальный продукт уходит из CS со скоростью kSP. Сигнал равен Phi_SP.

| Файл | Что проверяет |
| --- | --- |
| `two_site.py` | модель и решение блочного уравнения прямым обращением лиувиллиана |
| `run_a_ciss_cases.py` | цепочка с CISS при рождении и при прыжке: точная чётность при рекомбинации только через проектор рождения в узле рождения (T1, T3, T3r, T7) и нечётная часть при любом другом канале (T4–T6); T2 даёт нечётную часть без CISS |
| `run_b_no_ciss.py` | без CISS: рекомбинация только из конечного узла (T9), зависимость от времени жизни мостика (T10), составная пара с быстрым обменом (T13, T13b), одинаковые гамильтонианы (T12), мостик с одним обменом (T12b), мостик без ядра второго радикала (T11) |
| `run_c_sanity_limits.py` | пределы, в которых чётность обязана быть точной |
| `run_d_denton_structure.py` | структура операторов Denton et al. (2026): один проектор P_theta при рождении и в обоих каналах рекомбинации, прыжки без поворота, мостик с гамильтонианом de·P_theta + 2J·P_S |
| `check_rk4.py` | независимая проверка случая T2 шагами Рунге – Кутты по блочным матрицам плотности, без супероператоров |

Столбцы журналов: наибольшая нечётная часть каждого выхода на 10 парах противоположных направлений, размах Phi_SP
по этим направлениям (грубая мера анизотропии) и отклонение суммы выходов от единицы.

Запуск: `python3 run_a_ciss_cases.py` и так далее (NumPy, SciPy).
